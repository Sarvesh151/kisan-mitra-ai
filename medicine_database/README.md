# Kisan Mitra AI - Medicine Database

This database currently contains verified/reference management options for
selected tomato disease/pest classes, based on official Indian agriculture
sources.

Important:
- These are reference entries, not personalized prescriptions.
- Always follow the current registered product label, PPE requirements,
  pre-harvest interval, and local agricultural/KVK/SAU guidance.
- A pesticide listed for a vector does not cure a viral disease.
- More crop/disease entries should be added after checking official
  crop-specific registration/recommendations.

Primary sources:
- PPQS, AESA based IPM – Tomato:
  https://ppqs.gov.in/sites/default/files/tomato.pdf
- PPQS/CIB&RC, 427th Registration Committee meeting minutes:
  https://ppqs.gov.in/sites/default/files/427_rc_minutes.pdf
